# PennyPilot

本地优先的个人记账应用。记录日常收支、整理支付账单、查看预算与月报，也可以用一句话或语音记账，用自然语言查询账本。

[下载 Android 版](https://github.com/will-bw/PennyPilot/releases/latest) · [使用指南](docs/USAGE.md) · [更新记录](CHANGELOG.md)

## 能做什么

- **随手记账**：支持手动、文字、语音和图片录入，自动补全日期与分类，识别后可直接保存，结果可撤销或修改。
- **支付采集**：Android 可从支付通知和可读取的支付结果页记录账单，结合历史与用户更正补全分类、用途和账户。
- **问账助手**：用自然语言查询收支、比较消费、分析预算，也能直接新增账单；修改、删除和预算调整需先核对。
- **预算与报表**：查看月度预算、每日支出、分类统计和历史月报。
- **账单导入**：支持微信、支付宝 CSV，导入前预览新增、疑似重复和冲突记录。
- **备份与恢复**：导出 JSON 账本备份，支持恢复与跨端迁移；提供浅色、深色和宽屏布局。

## 安装与开始使用

当前版本为 **v0.7.0**，支持 Android 8.0 及以上。从 [GitHub Releases](https://github.com/will-bw/PennyPilot/releases/latest) 下载 APK，按系统提示确认安装。目前尚无对外分发的 iOS 安装包。

安装后即可手动记账。首次使用可按需要开启权限，也可跳过，之后从「设置 → 权限设置」继续。文字、语音、图片识别和问账需先配置对应的模型服务或登录账号，详见 [使用指南](docs/USAGE.md)。

已有用户可从「设置 → 数据与应用 → 检查更新」下载新版，覆盖更新会保留本地账本和设置。

## 数据与隐私

账本保存在设备上，目前没有自动云同步，请按需要手动导出备份。使用 AI 时，相关输入、对话上下文和必要账本数据会发送给所选服务；语音转写与云端识别可能消耗服务额度。

支付采集仅适用于 Android，需要相应系统权限，能否识别取决于支付应用提供的通知和页面内容；漏记时可主动补录或导入账单。问账会话和长期记忆目前不包含在账本 JSON 备份中。
