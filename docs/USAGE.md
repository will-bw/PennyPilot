# 使用 PennyPilot

## 开始记账

安装后即可手动记录收支。首次打开应用时，可以按需要逐项开启权限，也可以跳过，之后从「设置 → 权限设置」继续设置。

账本中的「记一笔」直接打开手动表单，无需配置 AI 即可使用。文字、语音和图片统一从底部「AI 助手」进入。输入“昨天晚上 7 点过吃盖饭，17 块钱”这类日常描述，助手会推断日期、分类和用途。

自动保存默认开启，结果可撤销或修改；已保存的关闭选择会继续生效。多笔输入中，明确的账单可先保存，缺少的信息可以继续补充，无需重填完整描述。未支付、未来计划、金额冲突等情况不能直接作为已发生账目保存。

AA 消费可在手动表单中开启「AA 制」，输入实付总额与包含自己在内的总人数；也可以告诉助手“聚餐付了 100 元，4 人 AA”。这笔账只将自己承担的 25 元计入支出，总额和人数会保留在账单中。分摊金额按分四舍五入；未说明人数时，助手会先询问。

## 配置 AI 与语音

文字识别和问账支持 ChatGPT 账号、DeepSeek、Qwen。在「设置 → AI 服务」配置所选服务；ChatGPT 登录后还需授权使用套餐用量，其他服务需填写相应 API Key。

DeepSeek 默认模型为 `deepseek-flash`，百炼默认为 `qwen3.8-flash`，默认地址为 `https://dashscope.aliyuncs.com/compatible-mode/v1`。已保存的模型和自定义地址会保留。各服务可独立设置对话的深度思考；可选档位以当前模型能力为准，始终思考的模型不能关闭。聊天输入框也能调整，发送后本轮配置固定。

「设置 → 识别与自动录入」可分别配置文字、视觉和复核模型。云端页面识别、图片识别与本地视觉补充按需开启；相关数据授权默认关闭，不会因为开启自动保存而一并开启。

语音转写需在「设置 → 语音模型」单独配置服务地址、转写模型和 API Key，ChatGPT 登录不会提供语音服务密钥。支持 Qwen ASR 和兼容 `/audio/transcriptions` 的服务，密钥需与服务地区及模型权限匹配。

配置后点击「开始测试录音」，说话后点击「结束并转写」。测试只返回文字，不新增账单。录音最长 60 秒；语音录入不依赖手机自带的识别服务。云端转写可能消耗所选服务额度。

## Android 支付采集

在「设置 → 权限设置」按需要开启通知使用权、无障碍和后台运行权限。在「设置 → 自动采集」开启「读取可见支付结果」，阅读说明并授权后，确认服务已连接。

支付完成后在结果页稍作停留，应用可从通知或可读取的页面记录账单，通知中可撤销或修改。结合商户历史和用户更正推断分类、用途及账户；单独授权模型后，可异步完善已捕获的账单。

采集覆盖微信、支付宝、云闪付、美团和抖音的常见支付结果。退款受理、处理中或失败状态不会作为到账记录；同一订单的后续凭证可补齐缺失字段和可靠交易时间，用户修改过的账目会保留。同额不同订单分别记录，无法确认是否重复时交由你核对。

支付凭证提供的信息可保留到「账单详情 → 支付详情」，包括商户、品牌与门店、收款对象、多个商品或服务、规格数量、订单说明、付款备注、支付渠道与扣款账户。会保留读取到的交易详情，读取不到的内容留空；不把整个聊天或页面当作支付资料收集。开启本地截图补充后，已识别金额和商品的只读支付结果也可继续补充详情；原有订单号去重保持生效。

开启对应来源的云解析后，AI 会结合这一订单已获授权的详情判断用途、分类并整理备注。后续读到新详情会更新自动记录的分类与说明，重复读取相同信息不会反复请求；你手动修改过的账目不会被自动覆盖。原始支付详情独立保留，不会只剩 AI 的概括。通知与页面的云解析分别授权，只有本地采集授权的页面详情不会随通知发送给 AI；商品单价、优惠和备注里的数字也不会替代实际支付金额。

已确认的支付会先保存并即时提醒，AI 分类和详情在后台继续补充。仍需 AI 识别的凭证会先提示“正在识别支付信息／尚未记账”，通过校验后才入账。后续只更新原提醒；划走通知后不会因为补充详情再次弹出。失败或未完成支付不会因此被提前记账。

新版默认使用高优先级支付提醒，并升级未经用户调整的旧静默渠道；已关闭或自行调整的通知设置会保留。若设置页显示提醒优先级较低，可从“设置支付提醒”开启横幅或悬浮通知；免打扰、系统横幅和后台限制仍会影响送达。升级和系统监听重连时会恢复已有识别任务，无需先打开账本。用于排查延迟的时间线只保存在本机，包含匿名事件标识与各处理阶段时间，不含商户、金额、订单号和通知正文，也不进入云备份。

微信转账没有系统通知时，可尝试页面采集。Android 14 及以上还可单独开启本地截图补充；支付应用没有提供可读取内容、页面受保护或金额无法辨认时，仍需主动补录或导入账单。

无法细分用途的真实资金变动先按资金转移记录，避免计入消费或收入。可在「自动采集」查看最近处理状态；需要排查漏记时，可主动采集一次诊断样本，预览后复制。

支付采集仅适用于 Android，iOS 不提供跨应用通知监听或支付页面采集。

## 用 AI 助手查询和记账

可以直接询问本月支出、比较分类消费或分析预算，也可以描述一笔或多笔新收支。回复会逐步显示，并支持表格、图片、图表与交互报告。查询过程可展开查看，金额依据能定位账单；向上阅读历史时不会被新内容拉回底部。

思考内容与正文分别流式显示，可展开查看耗时、各次模型响应及中断状态。GPT 展示服务商提供的公开思考摘要，DeepSeek 和百炼展示返回的思考内容；服务商没有返回可展示内容时会明确说明。思考记录随本机对话保存。

点击麦克风开始录音，结束后将转写文字填入输入框，允许修改后再发送。点击图片按钮可选择凭证，添加补充说明后发送；从系统分享的凭证也会进入助手。图片识别的待补充信息和草稿可以在同一对话中继续处理，批量核对时可只保存选中的账单。CSV 导入从助手的更多操作进入，仍在本机解析并提供去重预览。

自动新增后能继续查询刚记下的账本；每轮保留结果回执，未被修改的新增账单可撤销。修改、删除和预算调整会先展示提案及核对按钮，执行后显示处理结果。停止只结束后续工作，已保存的账单保留。回答中断后重试会继续处理和核对当前账本，避免重复新增。

图表和交互内容可在聊天中查看、全屏展开或保存。历史图表保留生成时的数据快照；需要最新结果时继续让助手重新查询。统计页的分析入口会把当前月份或分类带入助手输入框，确认问题后发送。

助手右上角可新建和管理对话、查看和删除记忆，并调整上下文预算与执行步数。会话、附件、交互内容和长期记忆保存在本机，目前不包含在账本 JSON 备份中；需要保留的图表和报告可以单独保存。

## 导入与备份

微信和支付宝 CSV 账单可先预览再导入，应用会区分新增、疑似重复和冲突记录；转账、借还款及退款按各自用途处理。

从「设置 → 数据与应用 → 导出账本备份」保存 JSON 文件，之后可通过「从备份恢复」恢复 Android 或 iOS 导出的账本。恢复会替换当前账本，请先导出当前数据；它不会合并两个账本，也不能在应用内撤销。

备份包含账单、分类、通知解析规则和月报，不包含登录凭据、API Key、问账会话或长期记忆。账本目前没有自动云同步，请将备份保存到自己信任的位置。

## 下载与更新

从 [GitHub Releases](https://github.com/will-bw/PennyPilot/releases/latest) 下载 Android APK，按系统提示允许当前安装来源并确认安装。目前仅提供 Android 安装包。

也可从「设置 → 数据与应用 → 检查更新」检查新版。选择「下载更新」，校验完成后选择「安装更新」；若需要安装授权，按提示前往系统设置，返回后继续。检查、下载和安装都由用户主动触发，最终安装由 Android 系统确认。

正式版本沿用同一发布签名，可覆盖更新并保留本地账本和设置。每版同时提供 `update.json` 与 `SHA256SUMS`；应用会校验下载大小、摘要、包名、构建号及签名。

## 数据使用

账本保存在设备上。启用 AI 后，相关输入、对话上下文、检索到的记忆和必要账本数据会按功能发送给所选服务。登录凭据与 API Key 加密保存在本机，不进入账本备份。
