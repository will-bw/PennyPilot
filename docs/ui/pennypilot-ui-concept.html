5关键设计决策

◆记一笔居 C 位：底部中央靛蓝大按钮，全局随时可记，符合「录入是最高频动作」。
◆待确认不强打扰：琥珀渐变行内提示 + 行内 [记入/忽略/编辑]，在列表里原位处理，不弹窗。
◆金额去符号化染色：支出墨色、收入暖红，正负号 + 色彩双编码，色弱友好。
◆AI 可识别：所有 AI 产物（解析预览、点评、对话）带 ✦ 标识与靛蓝色系，与人工数据区分。
◆服务状态显性化：捕获服务做成「活的健康卡」，绿色呼吸点 + 三项指标，ColorOS 保活焦虑可视化。

?留给讨论的问题

2流水页顶部的「近 30 日支出节奏条」保留，还是换成环形分类占比？
3报告页的衬线「七月账本」杂志标题风格，要不要贯穿到全 App 页面标题？
