# Flutter 主应用
Mode: Operate

用户方向：生活账本型，柔和色彩、有一点亲切感。
使用场景：支付后快速录入，晚间核对自动采集，本月回顾支出与预算。

首屏：纸白页面，雾蓝分组底。本月支出是首要金额，收入和结余为次要金额。预算一行可点，待核对用暖杏色单行提示。搜索按需展开，收支筛选始终可用；真实日期的日号、星期和小计组织流水。右下「记一笔」一步进入录入。

识别细节：日期组配合柔色分类圆标；金额按列对齐，深色和小屏大字仍可读。分类优先读取已配置图标。所有色彩从 DESIGN.md 的语义表取得。

完成路径：手动/一句话/语音 → 可编辑核对 → 明确保存 → 流水出现；采集 → 待确认 → 入账/忽略。
不同状态：真实空账本、权限缺失、AI未配置、网络失败、搜索无结果、恢复后草稿失效、预算超支。

应用更新：入口为「设置 → 数据与应用 → 检查更新」，沿用现有 Material 浅底分组、圆角、语义色与原生按钮。显示当前版本和发布说明，检查、下载、安装均由用户主动点击；下载显示进度并可取消，失败保留对应重试操作。缺少安装权限时打开系统授权页，返回后点击「授权后继续安装」，安装仍由系统确认。iOS 可检查版本和查看发布说明，不提供 APK 下载或安装。

验证：320/390 手机、1.5倍字号、明暗、宽屏；Flutter静态检查、行为回归、组件渲染截图及移动构建。截图使用独立合成夹具，不能作为真实账本或实际权限/OAuth/语音结果。
