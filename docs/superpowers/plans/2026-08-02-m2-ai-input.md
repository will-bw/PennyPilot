# M2 AI 录入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现自然语言（文字+语音）记账，LLM 解析一句话为多笔结构化交易，预览后一键保存。

**Architecture:** LLMClient 接口抽象 → DeepSeek/Qwen 双实现 → ParseTextUseCase 组装 prompt + 解析 JSON → InputDock 复用组件（文字+语音）→ 记一笔页面升级为 AI 解析预览卡。ASR 第一版用 Android SpeechRecognizer（零配置），Paraformer 留接口后续替换。

**Tech Stack:** OkHttp 4.12 + kotlinx.serialization 1.7（LLM HTTP）, Android SpeechRecognizer（ASR）, EncryptedSharedPreferences（Key 存储）
