# M3 通知捕获 + M4 洞察 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development

**Goal:** M3 实现微信/支付宝通知自动捕获记账；M4 实现对话查账 + 月度报告 + 备份。

---

## M3: 通知捕获 (6 Tasks)

### Task 1: parse_rules 数据层
- ParseRuleEntity + ParseRuleDao + 预置微信/支付宝正则规则
- AppDatabase 升级（version 2 + Migration 或 fallbackToDestructiveMigration）
- DI 提供 ParseRuleDao

### Task 2: ParseRuleEngine + CaptureServiceMonitor
- ParseRuleEngine：按 priority 逐条正则匹配，返回 ParseResult(amount, merchant, direction)
- CaptureServiceMonitor：@Singleton StateFlow<ServiceHealth>(bound, lastNotifTime, todayCount)
- 单元测试：正则匹配 fixture

### Task 3: NotificationListenerService
- onNotificationPosted：过滤包名 → 去重 → ParseRuleEngine → Room PENDING → 发本地通知
- onListenerDisconnected：requestRebind
- AndroidManifest 注册 service + BIND_NOTIFICATION_LISTENER_SERVICE 权限

### Task 4: NotificationActionReceiver + 本地通知
- BroadcastReceiver 处理 [记入][忽略][编辑] 按钮
- NotificationHelper：构建带 action 的通知
- 编辑按钮 → 打开 App edit/{id} 页

### Task 5: ColorOS 引导 + 设置页升级
- OnboardingActivity/Dialog：通知使用权 + 自启动 + 电池优化引导
- 设置页：服务健康卡（呼吸点 + 三指标）+ ColorOS 保活引导入口
- BootReceiver：开机检查服务

### Task 6: M3 集成验证
- 编译 + 测试 + 提交

---

## M4: 洞察 (5 Tasks)

### Task 7: InsightUseCase (Function Calling)
- Tool 定义 JSON（query_transactions, aggregate_by, compare_periods）
- DAO 扩展查询（聚合、分组）
- Function call 解析 + 本地执行 + 结果回喂
- ChartData 生成

### Task 8: 问问页面 (Chat)
- ChatViewModel：消息列表 + 推荐问题 + 调用 InsightUseCase
- ChatScreen：气泡 UI + MiniChart + InputDock 复用
- NavGraph 替换 CHAT 占位

### Task 9: 月度报告
- MonthlyReportWorker (WorkManager)
- ReportViewModel + ReportScreen（Hero 卡 + AI 点评 + Top3 + 历史列表）
- monthly_reports DAO
- NavGraph 替换 REPORT 占位

### Task 10: 备份功能
- BackupUseCase：导出/恢复 .db 文件到 Documents/PennyPilot
- 设置页备份入口 + last_backup_at DataStore

### Task 11: M4 集成验证
- 全部测试 + 编译 + 最终提交
