# PennyPilot UI 与交互精修 · 2026-10-22

本轮从 `be3a1d3` 开始，按照用户选择的“保留现有风格，全面精修视觉和交互”落实修改。保留靛蓝主色、浅冷色背景、圆角卡片、大金额展示和原有页面结构，重点改善信息层级、输入效率、反馈完整性以及小屏／深色／宽屏适配。

没有引入新的依赖或数据库迁移。修改包含界面及其直接依赖的状态管理，保留此前账本写入保护、备份确认和数据一致性约束。

## 视觉与布局

| 范围 | 完成的修改 | 用户可见的作用 |
|---|---|---|
| 色彩 | 保留 `#3B54E1` 主色与 `#F3F5FA` 浅色背景；提高次级文字、输入框轮廓和趋势柱的对比度；区分控件轮廓和装饰分隔线。 | 搜索框、辅助信息和小额趋势更容易辨认。 |
| 字体 | 统一正文、标签和标题层级，正文采用 16／14／12 sp 层级，保留大金额和原有标题风格。 | 各页面字号与信息密度更一致。 |
| 导航 | 窄屏使用 Material 导航栏，记账入口有独立图标和文字；600 dp 起改为侧边导航；内容最大宽度 840 dp。 | 小屏入口清晰，宽屏内容不再无限拉伸。 |
| 页面边界 | 二级页面隐藏主导航；处理系统安全区、键盘和已消费的窗口 Insets。 | 编辑页面有更充足的空间，底部操作不会与主导航争抢位置。 |
| 组件 | 增加共享加载／空状态／错误卡片，统一表单、类别选择及管理页组件，主要操作使用至少 48 dp 触控区域。 | 空页面有下一步提示，出错后有恢复入口。 |
| 深色主题 | 金额、输入框、消息气泡和次级文字使用应用主题色。 | 收入色不再受系统主题与应用主题不一致影响。 |

窗口处理和语义参考 Android 官方 [Insets 指南](https://developer.android.com/develop/ui/compose/system/insets)及[无障碍语义指南](https://developer.android.com/develop/ui/compose/accessibility/semantics)。本轮增加语义和触控区域，不代表已经完成 TalkBack 人工验收。

## 主要操作流程

### 记账、预览与编辑

- 输入页采用可滚动内容和稳定的底部操作区域，发送、识别、保存状态有明确反馈，重复操作会被拦截。
- 解析出的账单预览使用稳定标识；继续解析时追加结果，避免索引变化导致编辑错条目。
- 预览可直接修改金额、收支类型、分类、日期、时间、商户和备注；移除条目需要确认。
- 手动记账支持独立日期／时间选择，选择的时间真正写入账本。输入备注时切换到系统键盘，自定义金额键盘让出空间，保存入口仍可见。
- 编辑页固定标题栏和保存操作，表单可滚动；无效金额、加载失败、保存失败分别反馈；有未保存修改时返回会提示。
- 编辑旧账目时保留原本已停用的分类并标记“已停用”，避免打开表单就悄悄换分类；其他新选项只使用启用分类。
- 语音识别补充权限反馈、识别中状态和页面离开清理逻辑；识别结果合并到当前草稿。

### 流水与统计口径

- 月份选择带年份，支持回到当前月；搜索作用于当月的商户、备注和分类。
- 待确认数量、待确认列表与当前月份保持一致；待确认账目明确标识“尚未计入统计”。
- 顶部展示整月已确认收支；筛选后的每日汇总与可见记录对应，减少筛选口径混淆。
- 长商户名称、金额和操作区域重新排布；待确认账目直接提供记入、忽略和编辑入口。
- 已确认账目提供操作菜单；删除和滑动删除有确认，写入失败提供 Snackbar 反馈。
- 趋势保留零值刻度，并提高非零柱的对比度；日期范围与统计含义用文字说明。

### 月报

- 没有生成 AI 报告时也能查看已有账目的实时图表。
- 分类图表改为带名称、金额和占比的横向条形图，降低标签拥挤；近六个月趋势补齐零值月份。
- 月度比较只针对相邻月份，避免把不相邻的历史报告误作环比。
- 消费热力图补充日期及可读语义；历史报告可展开详情，并针对选中月份重新生成。
- 报告生成状态跟踪实际 WorkManager 任务，包括排队、执行、成功和失败；使用 KEEP 策略时跟踪实际保留的任务，而非未运行的新请求。

### “问问”

- 空状态展示示例问题，回答文本可选择复制，消息使用应用主题色。
- 发送中防止重复提交；失败后展示清晰反馈和重试入口。
- 重试复用失败问题，不重复插入用户消息，也不把错误文案作为对话上下文；用户新输入的草稿不会被重试覆盖。
- 清空对话需要确认，移除当前未实现的麦克风入口，并将技术性提示替换为用户能理解的文案。

### 设置、分类与规则

- 设置页统一图标、行高和分组；权限、通知监听和电池设置展示实际状态，不再把完成跳转等同于设置完成。
- 无操作的设置项不显示跳转箭头；备份、恢复及偏好写入有忙碌状态和失败反馈。
- 首次通知权限请求增加持久化标记，拒绝后不再由启动逻辑主动反复弹出。
- 首次引导可滚动并适配安全区；区分可选权限，ColorOS 指引保留系统设置回退和失败提示。
- 分类操作收进菜单；新增／编辑先验证，异步保存成功后再关闭，删除和重排保持事务处理。
- 规则表单可滚动，增加输入验证、运行中反馈和模式测试；保存／删除／重置有相应确认与错误保留，规则测试离开主线程。
- AI 配置按服务商显示字段，密钥可切换显示，验证模型名及 HTTPS 地址；未保存修改有离开提示，保存结果有反馈。密钥草稿保留在内存，不写入页面状态 Bundle。
