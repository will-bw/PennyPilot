# 记账流程交互优化 · 2026-10-23

保留 Jetpack Compose、Material 3、现有主题和主导航方式，优化「输入 → 识别 → 核对 → 保存」。

## 改动

- 统一流程提示区：输入提示、识别中、核对、保存中和完成结果采用短暂的先淡出后淡入过渡，避免文字重叠。识别中保留刚提交的原文。
- 核对列表沿用草稿稳定 ID，新增、移除和位置变化有短过渡；整张卡片可以打开修改表单，仍保留明确的修改、移除按钮与移除确认。
- 核对表单确认或取消时先完成底部弹层收起动画，再移除弹层；正在关闭时不能重复应用修改。
- 保存期间显示固定的核对列表快照，避免数据库逐笔写入导致卡片逐笔消失。真实待保存列表仍在每次写入成功后移除对应草稿，失败后只留下未成功条目。
- 成功后显示本次保存笔数、支出及收入金额，并提供「查看流水」入口；允许直接继续输入下一笔。完成金额来自核对后的条目，部分失败后重试的完成结果仅统计该次重试实际保存的条目。
- 保存按钮平滑展开、收起；保存过程中只保留保存按钮的进度提示，避免输入区同时出现第二个保存加载圈。
- 输入框焦点边框和多行高度短暂过渡；空白提示保持单行，避免大字体下无输入内容却占据两行。真实输入仍支持多行。
- 记账页底部导航按实际键盘 inset 收缩，避免用第二套动画时钟追赶键盘。键盘打开时隐藏该导航的无障碍语义。其他主标签切换方式沿用原实现。
- 动画使用 Compose 标准机制，遵循系统动画缩放设置，没有引入新依赖或人为延长生产流程的等待时间。
