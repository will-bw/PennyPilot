# Flutter UI 重设计 · 2026-10-23

## 范围与版本

先按要求将改版前的全部工作区更改保存为 `90e63d6`（Flutter 迁移、自动采集、输入流程和 ChatGPT 流兼容等已有工作），随后独立修改 Flutter UI。用户确认的方向是「生活账本型：柔和色彩、有一点亲切感」。本轮不更改账本存储、原生采集服务、AI 请求协议或权限能力。

## 设计与实现

调研来源与视觉规范见 [DESIGN.md](../../DESIGN.md)。实际查看 Spendee 和 YNAB 官方产品展示，结合 YNAB 的搜索说明及 Monzo 的趋势结构；Mobbin 因付费限制未取得图像，不作为证据。

- 纸白页面、雾蓝操作色、暖杏待核对提示；收入另用柔绿，分类采用低饱和色。明暗主题逐项定义，避免默认种子色扩散到整个界面。
- 账本金额层级、预算余量、待核对入口、日期分组和流水重新编排。流水金额右对齐；小屏大字改为纵向金额。日期小计只统计当前筛选结果中的已确认记录。
- 搜索默认收起，通过标题栏展开；收起与切换页面都保留关键词，提供清空入口；收起时提示当前搜索条件。
- 统计移除重复宣传式标题，改为汇总、日支出、分类和月度回顾。每日选择与分类钻取保持。
- 手动录入突出金额，分类改网格，补充信息集中排版，保存固定在底部。一句话、语音、核对、保存流程保持。
- 问账使用问题行与简洁正文，减少大图标、同义文案与消息容器；发送提示、失败、清空确认保持。
- 设置与子页统一为柔和分组行；不改变平台能力、备份双重确认、未保存离开保护。
