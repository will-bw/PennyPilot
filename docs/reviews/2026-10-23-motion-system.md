# 全 App 动效与交互连续性优化

日期：2026-10-23。范围：PennyPilot 原生 Android 应用的全部主要界面。

## 实现方向

保留 Kotlin、Jetpack Compose、Material 3、现有五个主入口及品牌样式。新增 `ui/theme/Motion.kt`，把应用自有动效集中为统一参数：空间变化使用阻尼比 1、刚度 500 的弹簧；颜色和图标反馈约 140–160 ms；内容进入 180 ms、退出 90 ms；页面方向过渡 280 ms。

弹簧可以从当前状态继续响应反向操作。文字较多的页面与状态采用先退出、再进入的 fade-through，避免交叠。实际请求、保存和导航在操作后立即执行，动画不增加业务等待。金额文本直接显示真实数值，不滚动插值出不存在的金额。

本次使用现有 Compose 稳定 API 完整实现，未更换框架、升级 Kotlin/Compose 依赖或引入 Rive/Lottie。它是应用自己的统一动效层，不声称接入了 Material 3 Expressive 的新组件 API。Material 自带的按钮涟漪、开关、菜单、对话框和弹层继续使用原生实现。

设计参考：[Material motion](https://m3.material.io/styles/motion/overview/how-it-works)、[Compose 动画](https://developer.android.com/develop/ui/compose/animation/introduction)、[原生返回](https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture)。

| 报告 | 生成状态与按钮内容连续变化；历史报告在同一条目内展开收起，箭头同步旋转，反向操作可打断；结果更新不清空整页 |

## 边界与性能约束

- 使用 Compose 动画时钟，跟随 Android 动画比例；没有自建无限帧循环、延时提交或依赖动画完成才开始网络请求。
- 未增加滚动入场、无穷呼吸/闪烁、整页骨架闪光或每个文字变化的布局动画。
- 保留原生触摸目标、返回和编辑防丢失处理；清除退出内容的可访问性语义，真实状态仍可读取。
- 数据层、数据库结构、LLM 请求、分类/规则业务逻辑均不属于本次全 App 动效改造。此前输入流程及 ChatGPT 流兼容修改继续保留。
